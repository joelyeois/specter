SPECTER
=======

**Scattering & Propagation of Electrons in Cryo-EM: Twin Emulator & Reconstruction**

SPECTER is a physics-based cryo-EM / cryo-ET simulator and 3D reconstruction engine.
It generates training data that closely matches experimental images and solves the
inverse problem (reconstruction) using the same forward model.
